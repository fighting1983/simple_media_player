# 简单媒体播放器 (Simple Media Player)

基于 Python tkinter + python-vlc 的轻量级桌面媒体播放器，支持视频和音频播放。

## 功能特性

- 播放 / 暂停 / 停止，独立暂停按钮
- 播放列表：默认隐藏（`Ctrl+L` 切换），双击播放，支持上一首 / 下一首，右键删除 / 清空
- 打开单个文件、多个文件，或递归扫描整个文件夹
- 播放结束自动播放下一首，支持三种循环模式（顺序播放 / 列表循环 / 单曲循环，控制栏 🔁 按钮切换）
- 退出时自动记住当前文件和播放进度，下次启动接着播；同时记住音量、倍速、循环模式、最近播放记录、窗口置顶状态（保存在 `player_config.json`）
- 最近播放：文件菜单下保留最近 10 个文件，点击直接播放
- 窗口置顶（视图菜单）、画面比例切换（`A` 键：原始 / 16:9 / 4:3 / 1:1）
- AB 复读（`B` 键：设 A 点 → 设 B 点开始复读 → 再按取消）
- 定时关机（工具菜单）：播完列表后自动关机，或 30 分钟后自动关机（60 秒倒计时，运行 `shutdown /a` 可取消）
- 进度条拖动跳转、时间显示
- 音量调节（数字实时显示）、静音切换
- 倍速播放（0.5x ~ 2.0x）
- 全屏模式：自动隐藏控制栏，鼠标移到屏幕底部时显示
- 单击视频画面 = 暂停 / 播放，双击 = 全屏切换
- 播放音频文件时，视频区显示封面画面（深色背景 + 音符 + 文件名），底部带随节奏跳动的装饰性柱状动画（纯装饰，非真实频谱；暂停时柱子回落静止）；在脚本目录放一张 `audio_cover.png` 可自定义封面图片

## 支持的格式

- 视频：MP4、AVI、MOV、MKV、FLV、WMV、WebM
- 音频：MP3、WAV、FLAC、M4A、AAC、OGG、WMA

## 环境要求

- Windows（点击画面暂停功能依赖 Windows API）
- Python 3.x
- [VLC 播放器](https://www.videolan.org/vlc/)（需与本机 Python 位数一致，同为 64 位或 32 位）
- python-vlc：

```bash
pip install python-vlc
```

## 运行

```bash
python simple_media_player.pyw
```

或直接双击 `simple_media_player.pyw`。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `Ctrl+O` | 打开单个文件 |
| `Ctrl+Shift+O` | 打开多个文件 |
| `Ctrl+F` | 打开文件夹 |
| `Ctrl+L` | 显示 / 隐藏播放列表 |
| `空格` | 暂停 / 播放 |
| `←` / `→` | 快退 / 快进 5 秒 |
| `↑` / `↓` | 音量 +/- |
| `[` / `]` | 倍速 -0.25x / +0.25x |
| `F` | 全屏 / 退出全屏 |
| `M` | 静音切换 |
| `A` | 切换画面比例 |
| `B` | AB 复读（设 A 点 / 设 B 点 / 取消） |
| `PgUp` / `PgDn` | 上一首 / 下一首 |
| `Esc` | 退出全屏 |
| 单击画面 | 暂停 / 播放 |
| 双击画面 | 全屏切换 |
